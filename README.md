# Proyecto POO – Comercializadora de Vehículos (Grupo 10)

Este repositorio reúne el desarrollo completo del proyecto de Programación Orientada a Objetos:  
una solución tecnológica para apoyar la gestión comercial de una empresa que comercializa vehículos.  

La idea central es acompañar el proceso desde que aparece un prospecto (cliente potencial) hasta la venta del vehículo, dejando todo documentado de forma clara, académica y sencilla.

---

## 🧩 Resumen por fases

- **Fase 0 – Contextualización del proyecto**  
  Se responde a las 5 preguntas clave del enunciado: qué debemos hacer, qué se necesita, qué objetos intervienen, cuáles se incluyen y cómo se genera la solución.  

- **Fase I – Requerimientos del sistema**  
  Se organizan los requerimientos en **9 grupos oficiales**, documentando cada uno con:  
  *Nombre, Descripción, Entradas y Salidas.*  
  Se integran requerimientos funcionales y no funcionales.

- **Fase II – Diseño de clases (POO)**  
  A partir del caso de estudio se construye la lista de sustantivos y se seleccionan las clases candidatas.  
  Se incluyen:  
  - Representación gráfica simplificada del diagrama de clases.  
  - Descripción de atributos y métodos de las clases principales.  
  - Tabla de documentación de atributos: *Nombre de la clase, Nombre del atributo, Nombre de codificación y Objetivo.*

- **Fase III – Codificación inicial de clases (diseño de métodos)**  
  Se definen los métodos principales de las clases (Prospecto, Cotización, Inventario, Orden de Venta, etc.) indicando:  
  *Nombre del método, Clase, Entradas, Resultado, Solución planteada y Firma esperada.*  
  Esta fase deja listo el puente entre el diseño y la futura implementación en Java.

- **Fase IV – Prototipos de interfaz y lógica de negocio**  
  Se diseñan prototipos de pantallas de entrada (registro de prospectos, interacciones, cotizaciones) y de salida (listados, detalle de cotización, reporte de ventas).  
  Además, se describe la lógica interna de los métodos clave usando condicionales y pasos narrados.

- **Fase V – Verificación, pruebas y cierre del proyecto**  
  Se verifica el cumplimiento de los 9 grupos de requerimientos, se plantean casos de prueba desde el registro de prospectos hasta el cierre de la venta y se hace una reflexión final sobre el proceso y el aprendizaje.
